# proves-formacio-3cat

Aquest repositori és un espai de proves creat durant la formació de GitHub Copilot Enterprise a 3Cat. La tecnologia avança ràpidament i les eines d'intel·ligència artificial estan transformant la manera com els equips de desenvolupament treballen dia a dia. Explorar noves possibilitats, aprendre en equip i aplicar els coneixements adquirits en entorns reals és fonamental per créixer professionalment. La col·laboració entre persones i màquines obre un horitzó ple d'oportunitats que encara estem aprenent a descobrir junts.
